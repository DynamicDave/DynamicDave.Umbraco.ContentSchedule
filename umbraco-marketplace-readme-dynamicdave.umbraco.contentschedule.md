# Content Schedule

See at a glance what is going live or offline. Content Schedule adds a dashboard to the Content section that lists every scheduled publish and unpublish action in your site.

## Features

- Filters for **Today**, **Next 7 days**, **Next 30 days** and **Overdue**, each with the number of entries
- Overdue shows scheduled actions whose time has passed but that were not applied
- Click a page name to open it
- Respects start nodes and permissions: editors only see the pages they may browse
- Read-only and zero configuration

## Compatibility

- Umbraco **17 and 18** (.NET 10)
- Backoffice UI in English, Dutch, German, French and Danish
- Free and open source (MIT)

## Getting started

```
dotnet add package DynamicDave.Umbraco.ContentSchedule
```

The dashboard appears in the Content section. Full documentation: [README on GitHub](https://github.com/DynamicDave/DynamicDave.Umbraco.ContentSchedule/blob/main/src/DynamicDave.Umbraco.ContentSchedule/README.md).
